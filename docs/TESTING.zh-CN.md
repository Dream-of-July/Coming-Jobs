# 这个测试版验证了什么

[English](TESTING.md) · [返回首页](../README.zh-CN.md)

## 可重复检查

```sh
node scripts/build-release.mjs
node --no-warnings --test plugins/coming-jobs/tests/*.test.mjs
node scripts/install.mjs --verify-only
node scripts/simulate.mjs
```

继承的运行时包含 183 项自动化回归测试，覆盖已确认事实、申请状态、内容授权、完整岗位范围、每日预算、材料基线、公司文字例外、批次中断恢复、上传阶段门槛和私有工作区迁移。这些都是合成测试，不向雇主发送投递。

安装器测试使用临时目录，浏览器辅助函数使用测试适配；通过测试不意味着兼容所有招聘网站。演示使用合成候选人和示例公司网址。

## 当前宿主证据及边界

更名前的 beta.8 在真实 Codex Desktop CUA 中完成过本地八字段普通表单测试，写前 checkpoint、逐字段写入/回读和插件回执均通过。测试发现过定位器读取超时，之后切换到宿主支持的只读控件查询。

| 稳定合成路径 | CUA 往返 | 整页读取 | 字段一致 |
| --- | ---: | ---: | ---: |
| 逐字段填写及整页回读 | 9 | 9 | 8 / 8 |
| 有限批次及字段回读 | 3 | 2 | 8 / 8 |

这是普通字段的局部对照，排除开发排查、插件调用和初始化；统计模型与 CUA 往返，不是底层浏览器请求或总 Token。附件前置条件为 fixture，不代表已在该次测试中完成真实上传，也不能推广为整次投递提速比例。

更名后的 beta.9 独立检查回归、安装、完整性和新 MCP 进程，不把 beta.8 的宿主证据说成一次新的 beta.9 真实投递。

## 已知限制

- 目前仅为 Codex Desktop 优化，macOS 是参考环境。
- 学校候选项、日期联动、简历解析和照片需要逐门户观察；文件名或 98% 进度不能证明附件已关联。
- 完整性只能检查已批准清单，不能编造缺失经历，也不能独立证明宿主提交的 PDF 提取文本。
- 经验验证和时间指标依赖宿主提供真实证据，不能把成功提交当作岗位匹配准确。
- 保存调度配置后，仍须成功绑定宿主才能称为已运行。
- 文档中英双语，部分运行时界面和校验文案仍为中文。
- 后续观察 3–5 次真实投递，再评价实际效率收益。

## 怎样反馈更有帮助

优先用合成页面和虚构候选值，提供插件构建、Codex Desktop 版本、预期、实际结果，以及是否保护了用户修改。不要上传真实简历、令牌、测评专属链接、完整聊天或含个人资料的截图。
