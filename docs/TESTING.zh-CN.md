# 验证范围

完整命令、覆盖项、合成门户与真实门户人工验收步骤见[测试说明](TESTING.md)。

双宿主无浏览器端到端测试纳入 npm test；另有真实 Chrome 离线渲染与可选 Playwright 三门户验证。Claude 上传和人工步骤在浏览器测试中由合成夹具模拟，不等于真实 Claude Desktop 已有自动上传能力。CI 配置覆盖 Node 22/24、macOS/Ubuntu；本地测试不能冒充远程 CI 结果。

## 十岗位中断与恢复

```sh
node --no-warnings scripts/application-batch-benchmark.mjs --engine synthetic
```

使用真实 SQLite、服务、队列和 checkpoint，加上合成表单：第一个岗位在第三项已写入后抛出异常，其余岗位继续；关闭并重开工作区后，再补齐中断岗位。脚本要求十份草稿全部就绪、80 个字段各写一次、每份附件上传一次、已完成进度保留，且最终提交点击与提交记录都为零。

同样的八个字段实际运行 beta.17 与当前执行器，直接浏览器 API 调用为 40 次与 25 次，减少 37.5%。同一申请、同一存储状态的完整/执行上下文也按实际 JSON 字节测量。调用次数不包含服务准备和门户保存；字节不是 token；本地夹具耗时不能当作真实招聘网站速度。

省略引擎参数时，脚本尝试已安装的 Playwright/Chromium，缺少时明确报告合成 DOM 模式。`--engine chromium` 强制真实浏览器路径，缺少即失败；不自动下载依赖。CI 在现有四组环境中运行合成模式。普通测试另外验证过期 worker 回收、领取与重试上限、公司资料变化、简历审核失效、别名额度、完整协议观察和默认只预填行为。
